Setup: Claude Code (verified working)

Add this to your project's .mcp.json (or run claude mcp add and paste the equivalent):

{
  "mcpServers": {
    "mc-econ-data": {
      "type": "http",
      "url": "{{ mcp_server_url }}",
      "headers": {
        "Authorization": "Bearer YOUR_KEY_HERE"
      }
    }
  }
}

Replace YOUR_KEY_HERE with the key above. Once added, ask Claude something like "what datasets are available from mc-econ-data?" to confirm it's connected.

Claude Desktop / claude.ai

Go to Settings → Connectors → Add custom connector, and paste in {{ mcp_server_url }}. No key needed -- you'll be asked to log into your Morning Consult Economic Intelligence account directly and approve the connection.

Calling it directly (for your own scripts/tools)

This is a standard MCP server (Streamable HTTP transport) at {{ mcp_server_url }}, bearer-token authenticated. Five tools: list_datasets, describe_dataset, query_dataset for data; list_methodology_docs, get_methodology for interpretation guidance. Any MCP client library (Python, TypeScript, etc.) can connect using the key above as the bearer token.
